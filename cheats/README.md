# Cheats index

`libretro-index.tsv` lists which cheat file of [libretro-database](https://github.com/libretro/libretro-database) belongs to which game, by game code and CRC32. It holds no cheat codes; the app downloads a game's cheat file from libretro-database when the player asks for it.

The index is derived from libretro-database at the commit named in its header, and shared under the same licence: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Credit: libretro-database contributors. Changes: reduced to game code, CRC32 and cheat file name.

The tools in `tools/` are under this repository's own licence.
