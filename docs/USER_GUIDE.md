# User guide

## Patch or cheat?

- **Patch** (`.ips`, `.bps`, `.ups` or `.xdelta`): changes the game as it starts, or makes a patched copy of it. Never overwrite your only copy of a game.
- **Cheat** (`.cht`): a list of codes you turn on in the emulator's cheat menu.

Each game's page says which one to use.

## Which version do I have?

A fix names the game code and the region, such as `ADAE` for a USA game. Emulators show the game code in the game's properties or its log. A fix made for another version may do nothing, or stop the game from starting.

## Cheats

The cheat files use RetroArch's `.cht` format.

- **DS codes** are Action Replay codes.
- **GBA codes** name their type (GameShark, Action Replay or CodeBreaker) in the file.
