# DS and GBA Game Fixes

Patches and cheats that fix and improve Nintendo DS, Game Boy Advance and Game Boy games. The sister repository of [3DS Game Fixes](https://github.com/simplysanatori/3ds-game-fixes).

There are no fixes here yet.

## Games

- DS: none yet
- GBA: none yet
- Game Boy and Game Boy Color: none yet

## Texture packs

None yet.

## How it works

- Each game has its own folder under `games/ds/`, `games/gba/` or `games/gb/`.
- A fix comes as a patch file, as a cheat, or both.
- Each fix is made for one region and version of the game.

## Requirements

- Your own copy of the game, in the region the game's folder names
- An emulator that reads the fix's format. Each game's page says which were tested.

## Install

Each game's page has its own steps. The [user guide](docs/USER_GUIDE.md) explains the file types.
